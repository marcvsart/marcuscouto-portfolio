# Estante de filmes — /sistemas/zombiebasilisk/
# Uma linha por filme. A ordem das linhas é a ordem das lombadas.
#
# arquivo-do-frame | título | data | palavras-chave separadas por vírgula | URL do vídeo
# Campos opcionais ao final: | crop horizontal% vertical% | descrição | texto do link | tipo | créditos
# Exemplo de crop: 50% 27%. Para descrição com crop padrão, deixe o sexto campo vazio.
# O frame aparece em 16:9. Sem esse campo, o recorte é centralizado (50% 50%).
# Valores de 0% a 100%: vertical menor privilegia o topo; maior, a base.
#
# Suba o frame em assets/img/filmes e acrescente a linha correspondente aqui.
# Use o nome exato do arquivo, inclusive maiúsculas e extensão.
# A data é texto livre: ano, mês/ano ou uma data completa confirmada por você.
# Não use o caractere | dentro dos campos. Não é necessário HTML.
# A URL deve começar com https:// ou http:// e apontar para o vídeo ou canal.
# A descrição aparece acima do frame; o texto do link padrão é "Assistir ao filme".
# Formatos: .jpg, .jpeg, .png, .webp, .gif, .avif.
# Linhas iniciadas por # são comentários e não aparecem no site.
