No UOL, desenho formatos audiovisuais com IA que se sustentam em série: uma linguagem visual codificada, uma estrutura de episódio e um fluxo de produção que permite publicar com regularidade sem refazer o método a cada vez. Cada série tem identidade própria; o que se repete é o sistema que a produz.
